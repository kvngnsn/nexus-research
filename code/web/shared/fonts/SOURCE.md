# Source Code Pro

Unmodified font files from [Adobe Source Code Pro](https://github.com/adobe-fonts/source-code-pro/tree/803b7e23ec97ae58b6232ea76519a76d428ba268).

- Revision: `803b7e23ec97ae58b6232ea76519a76d428ba268`
- Regular and Semibold WOFF2 files serve the browser interface.
- Regular TTF supplies the generated molecular diagrams.
- License: [SIL Open Font License 1.1](OFL.md).

All files are served locally. No font service is contacted at runtime.
