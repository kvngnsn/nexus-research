    Local and open-source models

    Bundled models and installers: In progress. No Ollama dependency or automatic download. An existing llama.cpp-compatible local server can be connected now using its /v1 endpoint and exact model ID.

    Local load controls and hardware measurements are not available in this version.

    Save findings

    Markdown and JSON update automatically after each response. Folder changes apply to new runs; saved runs keep their original location.

    Run budget

    Stops after productive search time or reported tokens without a new route passing configured graph checks. This does not prove every possible method has been found.

    Per-call limits and estimated spending

    Enter current provider rates. The worker reserves each call before generation. Spending is a conservative estimate, not an invoice guarantee.

    CLI usage is reported after a call. Limits stop subsequent calls; one in-flight call may exceed a token limit or continue billing after cancellation. API output limits do not constrain CLI output.

    Your research

    Nexus makes no ownership claim over your findings. No Nexus account, reporting service or telemetry.

    Only your selected AI provider receives prompts when you run research. A local model uses your own server. API keys stay in macOS Keychain.

    Local recovery history

    Checkpoints and pathway history stay on this computer. If your chosen drive becomes unavailable, research stops and received work remains here for export.

    Connections

    Named accounts, never key values. CLI sign-in stays with its own app. API keys are stored in macOS Keychain.

    Your selected provider receives submitted research. Its account terms and charges apply. Confirm its retention settings before a run.
