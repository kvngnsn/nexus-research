# Nexus Research

Start with `../README.md`, then `README.md`. Run developer commands from `code/`. Update `../todolist.md` at the end of each task with completed work, validation and remaining work.

- This is the standalone, MIT-licensed research app. Keep unrelated route explorers and economic calculators out.
- Python belongs in `nexus_research/`, browser assets in `web/`, the native shell in `desktop/`, developer tools in `scripts/`.
- Keep the interface monochrome and minimal, with bundled Source Code Pro and accessible text controls.
- Research uses only user-selected API keys, connected CLIs or localhost models. No Nexus account, hosted database, telemetry, enrollment, reporting or ownership terms.
- Save findings automatically as JSON and Markdown in the user's chosen folder. Preserve local checkpoint recovery, atomic pathway claims and explicit budgets. Stop on output failure; never auto-resume.
- Credentials stay in Keychain or the user's CLI. Never put keys in browser storage, records, logs, exports or bundles.
- Private/generated folders (`data/`, `.local/`, `.venv/`, `dist/`) are ignored. Do not inspect or migrate private stores for development; use synthetic fixtures.
- Run `make check` and `make verify-app` for packaged changes. No paid model calls in QA.
- Graph checks establish structural consistency only. Sources, feasibility and prices remain unverified; missing costs stay unknown.
- Public releases must have no private history, hardcoded deployment configuration, personal records or identifying build paths. Preserve third-party notices.
